# VideoCMS — 产品文档

> **语言:** [English](product.md) | 中文 | [Français](product.fr.md) | [日本語](product.ja.md) | [Deutsch](product.de.md)

## 1. 产品简介

VideoCMS 是一个自托管的视频资源管理系统。把服务器磁盘上的文件夹指定给它，扫描一次，
所有视频就变成一个可浏览、可搜索的媒体库——带海报、元数据、观看进度、收藏、播放列表，
以及按序号自动归组的「剧集」分类。

系统采用 **Go + React + PostgreSQL** 构建，完全运行在你自己的硬件上。
除非你主动分享，否则视频不会离开你的网络。

## 2. 功能特性

| 领域 | 能力 |
| --- | --- |
| 媒体库 | 任意服务器文件夹；支持手输路径或内置目录选择器 |
| 扫描 | 自动发现 mp4/mkv/webm/avi/mov/ts…，实时进度，可随时取消 |
| 元数据 | ffprobe 提取编码/分辨率/时长，自动生成海报，可编辑标题/年份/简介/类型 |
| TMDB 刮削 | 可选在线补全：本地化标题、简介、类型与海报 |
| 播放 | 浏览器内 H.264/WebM 原生播放；MKV/HEVC 自动 HLS 转码 |
| 剧集 | 带序号的视频（S01E01、EP1、第1集…）自动按集数排序归组为剧集 |
| 个性化 | 继续观看、收藏、可顺序播放的播放列表 |
| 用户 | 注册/登录、管理员角色、管理员用户管理 |
| 内容屏蔽 | 管理员按标题屏蔽媒资——对所有人隐藏，文件和记录保留，可随时解除 |
| 界面 | 5 种语言：English（默认）、中文、Français、日本語、Deutsch |

## 3. 快速开始

### 运行环境

- 服务器（macOS/Linux/Windows），构建需要 Go 1.22+（或使用预编译二进制）
- PostgreSQL 14+
- ffmpeg/ffprobe（用于元数据、海报与转码）
- Node.js 18+（仅前端开发需要；生产界面由后端直接托管）

### 安装

```bash
createdb videocms                       # 或：docker compose up -d db
cd backend && go run ./cmd/server       # 首次启动自动建表 + admin/admin123
cd frontend && npm install && npm run dev   # http://localhost:5173
```

局域网/手机访问，构建一次、单端口即可：

```bash
make serve                              # http://<局域网IP>:8080
```

### 首次登录

打开网页，用初始管理员 **admin / admin123** 登录（登录后请立即在
管理 → 用户管理 → 重置密码 修改）。

### 添加第一个媒体库

1. 进入 **管理 → 媒体库**
2. 填写名称，输入服务器文件夹路径或点击「浏览…」直接选择
3. 点击「扫描」— 数量实时增长，完成后首页即可看到视频

## 4. 使用指南

### 4.1 浏览与搜索

- 首页包含：继续观看、剧集、视频网格
- 搜索匹配标题、简介和文件名
- 可按媒体库和类型（全部/电影/电视剧）筛选，按标题/年份/时长/入库时间/收藏数排序
- 「加载更多」分页浏览

### 4.2 播放视频

- 点击视频进入详情页（海报、元数据、简介）
- 点「播放」开始；有进度时自动续播
- H.264 MP4 / WebM 原生播放；MKV/HEVC 实时转码
  （首次播放需等几秒；失败时可点「转码播放」兜底）
- 提供「下载」以便离线或本地播放
- 进度每 5 秒及暂停/结束时保存，体现在「继续观看」

### 4.3 收藏与播放列表

- 详情页点「☆ 收藏」，在「我的收藏」中管理
- 可从播放列表页或任意视频（「+ 添加到播放列表」）创建列表
- 播放列表支持顺序播放（▶ 顺序播放），带可视队列

### 4.4 剧集

文件名带集数标记的视频会在扫描后自动归组。支持的格式：
`S01E01`、`E01`、`EP1`、`第1集`、结尾数字（如 `1 (4)`、`-535`）。
同前缀 + 同季的组内至少 2 集才会形成剧集。

- 「剧集」页面列出所有剧集（海报 + 集数）
- 剧集详情页按 季 → 集 排序展示
- 每次扫描自动重建；可用集数不足 2 集的剧集自动清理

### 4.5 播放技巧

- 播放器使用浏览器原生控件——**空格** 播放/暂停、**F** 全屏、**←/→** 快进快退、
  **↑/↓** 音量、**M** 静音
- 观看进度自动续播；首页「继续观看」从上次位置开始
- MKV/HEVC 会实时转码为 HLS——首次播放需等几秒，之后跳转、下一集自动连播都正常
- 转码播放采用多档自适应清晰度——用播放器上方的清晰度选择器切换（默认自动）
- 字幕（外挂、内嵌或上传的）可在播放器中开关
- 手机横屏体验最佳；可用播放器下方的队列在剧集间切换

### 4.6 分享

- 打开视频并点击**分享**即可生成链接（默认 7 天，可设为 1 小时至 1 年）
- 拿到链接的任何人无需账号即可在公开页面观看该视频
- 链接自动过期，也可以随时在同一个弹窗中撤销
- 分享内容同样遵循管理控制：被屏蔽的标题和媒体库不会出现在分享链接中

## 5. 管理指南

### 5.1 概览

统计：视频、媒体库、用户、播放列表、收藏、剧集与占用空间。

### 5.2 媒体库

- 名称 + 服务器路径添加（含目录选择器）
- 「扫描」收录新增/变更文件；「停止扫描」取消；进度实时
- 删除媒体库会移除其视频记录——磁盘文件不受影响
- 「打开文件夹」会在服务器上用系统文件管理器打开媒体库目录，
  方便直接查看或管理实际媒体文件
- 「屏蔽媒体库」可将整个媒体库对所有人隐藏（首页、剧集、收藏、继续观看、
  播放列表全部生效），不删除任何文件与记录，解除后立即恢复

### 5.3 视频

- 搜索任意视频并编辑标题/年份/类型/简介
- 上传自定义海报
- 「刮削」从 TMDB 拉取元数据（需 `TMDB_API_KEY` 且能访问 api.themoviedb.org）

### 5.4 用户

- 修改角色（普通用户/管理员）、重置密码、删除账号
- 安全守卫：不能删除自己；最后一个管理员不可删除或降级

### 5.5 屏蔽内容

- 可按标题（例如剧名）屏蔽任何媒资，无需删除文件或记录
- 被屏蔽的内容对所有用户隐藏，覆盖首页、剧集、收藏、继续观看与播放列表；
  解除屏蔽后立即恢复
- 可先用搜索框预览某个标题会命中哪些媒资，再决定是否屏蔽

## 6. 配置

全部通过环境变量配置（完整表见 README）。常用项：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `PORT` | `8080` | 监听端口 |
| `DATABASE_URL` | `postgres://localhost:5432/videocms` | 数据库连接 |
| `JWT_SECRET` | 开发用值 | **生产必须设置强密钥** |
| `TMDB_API_KEY` | 空 | 启用元数据刮削 |
| `SCAN_WORKERS` | `4` | 并行扫描工作数 |
| `WATCH_INTERVAL` | `30` | 自动增量扫描间隔（秒），`0` 关闭 |

## 7. 常见问题

**为什么媒体库长时间显示「扫描中」？**
大文件夹首次扫描较慢（每个文件都要 ffprobe + 生成海报）。进度实时显示，可随时停止；
再次扫描只处理变更文件，快得多。macOS `._` 文件和 `.m3u8` 分片目录会自动跳过。

**为什么浏览器播不了 MKV/HEVC？**
浏览器只解码 H.264/VP9。VideoCMS 会把 MKV/HEVC 实时转码为 HLS，
也可以下载后用本地播放器播放。

**剧集是怎么识别的？**
文件名含 `S01E01`、`E01`、`EP1`、`第1集` 或结尾数字，按共同前缀归组，
每组至少 2 集。如果你的命名规则没被识别，请调整文件名或联系维护者增加规则。

**TMDB 刮削失败。**
检查是否设置了 `TMDB_API_KEY`，以及服务器能否访问 api.themoviedb.org。
受限网络下刮削不可用，但其他功能不受影响。

**手机怎么访问？**
手机与服务器在同一网络。执行 `make serve`，用 `ipconfig getifaddr en0` 查服务器 IP，
浏览器打开 `http://<IP>:8080`。首次运行若 macOS 弹防火墙提示，允许即可。

**能直接暴露到公网吗？**
默认是明文 HTTP + 开发用 JWT。若需公网访问，请配置 HTTPS 反向代理并设置 `JWT_SECRET`。

**如何在不删除文件的情况下隐藏内容？**
管理员可在「屏蔽内容」页按标题屏蔽，或在「媒体库」页一键屏蔽整个媒体库；
被屏蔽的内容会对所有用户在所有位置隐藏，解除后立即恢复。普通用户也可以
通过路径过滤隐藏任意服务器路径（仅对本人生效）。
