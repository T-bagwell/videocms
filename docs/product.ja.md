# VideoCMS — 製品ドキュメント

> **言語:** [English](product.md) | [中文](product.zh-CN.md) | [Français](product.fr.md) | 日本語 | [Deutsch](product.de.md)

## 1. VideoCMS とは

VideoCMS はセルフホスト型のビデオリソース管理システムです。サーバーのディスク上の
フォルダを指定して一度スキャンするだけで、すべての動画がブラウズ・検索可能な
メディアライブラリになります。ポスター、メタデータ、視聴履歴、お気に入り、
プレイリスト、連番ファイルを自動グループ化する「ドラマ」カテゴリも備えています。

**Go + React + PostgreSQL** で構築され、すべて自前のハードウェア上で動作します。
共有を選ばない限り、動画がネットワーク外に出ることはありません。

## 2. 機能一覧

| 分野 | 機能 |
| --- | --- |
| メディアライブラリ | サーバー上の任意フォルダ。パス入力または内蔵フォルダ選択 UI |
| スキャン | mp4/mkv/webm/avi/mov/ts… を自動検出。リアルタイム進捗とキャンセル対応 |
| メタデータ | ffprobe でコーデック/解像度/再生時間、動画からポスター自動生成、タイトル/年/あらすじ/ジャンル編集可 |
| TMDB スクレイピング | 任意のオンライン補完：ローカライズされたタイトル、あらすじ、ジャンル、ポスター |
| 再生 | H.264/WebM はブラウザでネイティブ再生。MKV/HEVC は自動 HLS トランスコード |
| ドラマ | 連番ファイル（S01E01、EP1、第1集…）をエピソード順に自動グループ化 |
| パーソナル | 続きを見る、お気に入り、連続再生できるプレイリスト |
| ユーザー | 登録/ログイン、管理者ロール、管理者によるユーザー管理 |
| コンテンツブロック | 管理者がタイトル単位でメディアをブロック — 全ユーザーに非表示、ファイルとレコードは保持、いつでも解除可能 |
| インターフェース | 5 言語：English（デフォルト）、中文、Français、日本語、Deutsch |

## 3. クイックスタート

### 必要な環境

- サーバー（macOS/Linux/Windows）。ビルドには Go 1.26+（またはビルド済みバイナリ）
- PostgreSQL 14+
- ffmpeg/ffprobe（メタデータ・ポスター・トランスコード用）
- Node.js 20+（フロントエンド開発のみ。本番 UI はバックエンドが配信）

### インストール

```bash
createdb videocms                       # または: docker compose up -d db
cd backend && go run ./cmd/server       # 初回起動でテーブル作成 + admin/admin123
cd frontend && npm install && npm run dev   # http://localhost:5173
```

LAN / スマホからのアクセスは、一度ビルドして単一ポートで：

```bash
make serve                              # http://<LAN IP>:8080
```

### 初回ログイン

初期管理者 **admin / admin123** でログインします（ログイン後すぐに
管理 → ユーザー管理 → パスワード再設定で変更してください）。

### 最初のライブラリを追加

1. **管理 → ライブラリ** を開く
2. 名前を入力し、サーバーフォルダの**絶対パス**（例: `/media/movies`）を入力するか
   「参照…」で選択します（相対パスは拒否されます）
3. 「スキャン」をクリック — 件数がリアルタイムに増え、完了後ホームに表示されます

## 4. ユーザーガイド

### 4.1 閲覧と検索

- ホームには「続きを見る」「ドラマ」「動画グリッド」が表示されます
- 検索はタイトル・あらすじ・ファイル名に一致
- ライブラリとタイプ（すべて/映画/ドラマ）で絞り込み、
  タイトル/年/再生時間/追加日/お気に入り数で並び替え
- 「さらに読み込む」でページング

### 4.2 動画の再生

- 動画をクリックして詳細ページ（ポスター、メタデータ、あらすじ）
- 「再生」で開始。進捗があれば自動で続きから
- H.264 MP4 / WebM はネイティブ再生。MKV/HEVC はリアルタイムにトランスコード
  （初回再生は数秒かかります。「トランスコード再生」もフォールバックとして用意）
- 複数の音声トラックを持つ動画は HLS 再生中に音声を切り替えられます
  （プレイヤーの音声セレクター）
- ダイレクト再生中に字幕を ±0.5 秒ずらして同期を調整できます（オフセットは
  ユーザー・動画ごとに保存）
- シークバーをホバーするとプレビューサムネイルが表示され、クリックでその位置に移動
- ASS/SSA 字幕は元のスタイル（フォント・色・位置・エフェクト）で表示されます
- 管理者は動画ごとにオンライン字幕源（例: OpenSubtitles）を検索して
  字幕をダウンロードできます
- **一緒に見る**：ルームを作成・参加して友人と再生を同期できます。
  ブラウザが対応していれば **キャスト / AirPlay** ボタンも利用可能
- **ライブ配信**：管理者が RTMP 配信（OBS 互換の取り込み URL）を作成でき、
  視聴者側には内蔵チャットがあります
- 管理者は動画の**音声文字起こし**（Whisper）を実行でき、文字起こしは
  検索可能で字幕トラックとしても選択できます
- 「ダウンロード」で選択した音声・字幕トラック入りの MKV/MP4 リマックス
  （再エンコードなし）を取得、または元ファイルをダウンロード
- 進捗は 5 秒ごと、および一時停止/終了時に保存され「続きを見る」に反映

### 4.3 お気に入りとプレイリスト

- 詳細ページで「☆ お気に入り」。「お気に入り」ページで管理
- プレイリストページまたは任意の動画（「+ プレイリストに追加」）から作成
- プレイリストは「▶ 連続再生」で再生でき、キューも表示

### 4.4 ドラマ

ファイル名にエピソードマーカーがある動画は、スキャン後に自動でグループ化されます。
対応パターン：`S01E01`、`E01`、`EP1`、`第1集`、末尾の数字（`1 (4)`、`-535` など）。
同じプレフィックス + シーズンで 2 話以上ある場合にドラマとして登録されます。

- 「ドラマ」ページにすべてのシリーズを表示（ポスター + 話数）
- シリーズ詳細は シーズン → エピソード順
- スキャンのたびに再構築され、2 話未満になったシリーズは自動整理

### 4.5 再生のヒント

- プレイヤーはブラウザ標準のコントロールを使用 — **Space** で再生/一時停止、
  **F** で全画面、**←/→** でシーク、**↑/↓** で音量、**M** でミュート
- 視聴進捗は自動で再開。ホームの「続きを見る」から前回の位置に戻れます
- MKV/HEVC は HLS にリアルタイムトランスコード — 初回は数秒かかりますが、
  その後はシークや次話の自動再生も通常どおり動作します
- 変換再生は多段階のアダプティブ画質を使用します — プレイヤー上部の画質
  セレクターで切り替えられます（既定は自動）
- 字幕（外付け・内蔵・アップロード済み）はプレイヤーでオン/オフでき、複数トラックが
  ある場合は言語を切り替えられます。ユーザーごとに動画ごとの既定字幕も設定可能
  （管理者はグローバル既定を設定可）
- スマホでは横画面がおすすめ。プレイヤー下のキューでエピソードを切り替えられます

### 4.6 共有

- 動画・ドラマ・プレイリストを開いて**共有**を押すとリンクを作成できます
  （既定 7 日間、1 時間〜1 年）
- リンクがあればアカウントなしで誰でも公開ページで視聴できます。ドラマや
  プレイリストのリンクはキュー全体を順番に再生します
- リンクは自動的に期限切れになり、同じダイアログからいつでも取り消せます
- リンクにはパスワードを設定できます — 公開ページではコンテンツ表示前にパスワードを求めます
- リンクを許可ドメインのリストに制限できます — 他のホストからのリクエストは拒否されます
- 共有コンテンツも管理設定に従います。ブロックされたタイトルやライブラリは
  共有リンクに表示されません

## 5. 管理者ガイド

### 5.1 概要

動画、ライブラリ、ユーザー、プレイリスト、お気に入り、ドラマ、使用容量の統計。

- **バックアップのエクスポート / インポート**：サーバーメタデータの完全な JSON バックアップを
  ダウンロード、または復元できます（ライブラリと動画はパスで冪等にマージ、個人データは
  既存ユーザーにのみ復元）

### 5.2 ライブラリ

- 名前とサーバーの**絶対パス**で追加（フォルダ選択 UI 付き）
- 「アップロード」タブ：任意のサーバーフォルダ（ライブラリ内など）へ
  チャンク/再開対応でアップロード。完了後は自動で取り込み
- 「スキャン」で新規/変更ファイルを登録、「スキャン停止」でキャンセル、進捗はリアルタイム
- ライブラリを削除すると動画レコードが消えます（ディスク上のファイルは保持）
- 「フォルダを開く」はサーバー上のライブラリディレクトリをシステムの
  ファイルマネージャーで開き、実際のメディアファイルを確認・管理できます
- 「ヘルスチェック」で欠落/破損ファイルと重複を報告。「最良版を保持」で
  他をサーバーのゴミ箱へ移動します
- 「NFO エクスポート / インポート」で動画の隣に Kodi 形式のメタデータを
  読み書きします（Plex/Jellyfin/Kodi 互換）
- 「ライブラリをブロック」でライブラリ全体を全ユーザーに非表示化
  （ホーム・ドラマ・お気に入り・続きを見る・プレイリスト）。ファイルと
  レコードは保持され、解除で即座に復元

### 5.3 動画

- 動画を検索し、タイトル/年/ジャンル/あらすじを編集
- カスタムポスターのアップロード
- 「ダウンロード」ダイアログで音声トラックと内蔵/アップロード字幕を選び、
  MKV/MP4 で保存（リマックス、再エンコードなし）
- 「取得」で TMDB からメタデータ取得（`TMDB_API_KEY` と api.themoviedb.org への
  アクセスが必要）
- 管理者は **TMDB またはカスタムプロバイダ** を選んで取得でき、既存メタデータを
  強制的に上書きもできます
- 動画には**タグ**を付けられます（手動、または任意の AI 解析ツールによる自動）。
  タグは詳細ページに表示され、検索の絞り込みにも使えます
- 詳細ページに**似ている動画**を表示。ブラウズページにはワンクリックで
  絞り込める**タグクラウド**があります
- ブラウズページで**フィルターを保存**・再適用でき、現在の条件から名前付き
  **スマートコレクション**を作成できます
- 検索には**あいまい関連度順**があり、タイプミスにも対応します
  （タイトル/概要/ファイル名）
- 管理の動画一覧で**一括操作**（タグ付け、タグクリア、ゴミ箱へ）と
  **ゴミ箱**（ワンクリック復元）が使えます

### 5.4 ユーザー

- ロール変更（一般/管理者）、パスワード再設定、アカウント削除
- ガード：自分自身は削除不可。最後の管理者は削除・降格不可

### 5.5 ブロック中のコンテンツ

- タイトル（例：作品名）単位でメディアをブロック。ファイルやレコードは削除されません
- ブロック中のタイトルはホーム・ドラマ・お気に入り・続きを見る・プレイリストの
  すべてで非表示になり、解除すると即座に復元されます
- 追加前に検索ボックスで、そのタイトルがどのメディアに一致するかプレビューできます

### 5.6 ダウンロード（yt-dlp）

- 動画/プレイリスト/チャンネルの URL をキューに追加。保存先フォルダ、
  yt-dlp フォーマット、任意の繰り返し間隔（時間）を指定 — サーバーが
  yt-dlp でダウンロード
- 進捗はリアルタイム、キャンセル可、失敗したジョブは再試行可
- 完了したファイルは選択したフォルダに保存され、ライブラリ内なら自動取り込み

## 6. 設定

設定はすべて環境変数です（一覧は README 参照）。主なもの：

| 変数 | デフォルト | 用途 |
| --- | --- | --- |
| `PORT` | `8080` | リッスンポート |
| `DATABASE_URL` | `postgres://localhost:5432/videocms` | データベース接続 |
| `JWT_SECRET` | 開発用値 | **本番では強力なシークレットを設定** |
| `TMDB_API_KEY` | 空 | メタデータスクレイピングを有効化 |
| `SCAN_WORKERS` | `4` | 並列スキャンワーカー数 |
| `WATCH_INTERVAL` | `30` | 自動インクリメンタルスキャンの間隔（秒）。`0` で無効 |
| `YTDLP_PATH` | PATH 上の `yt-dlp` | ダウンロードキューが使う yt-dlp バイナリ |
| `HLS_HW_ACCEL` | 空（ソフトウェア x264） | HLS ビデオエンコーダー：videotoolbox、nvenc、qsv または vaapi。空なら libx264 |
| `HLS_VAAPI_DEVICE` | `/dev/dri/renderD128` | VAAPI レンダーデバイス（`HLS_HW_ACCEL=vaapi` 時） |
| `HLS_TONE_MAP` | `0` | `1` で HLS トランスコードに HDR→SDR トーンマッピングを有効化 |
| `SUBTITLE_OS_USERNAME` / `SUBTITLE_OS_PASSWORD` / `SUBTITLE_OS_API_KEY` | 空 | オンライン字幕検索用の OpenSubtitles 認証情報 |
| `RTMP_INGEST_URL` | `rtmp://localhost:1935/live` | RTMP 取り込みのベース URL（nginx-rtmp 等） |
| `WHISPER_BIN` / `WHISPER_MODEL` | 空 | whisper.cpp のバイナリとモデル（文字起こし用） |
| `SCRAPE_CUSTOM_URL` | 空 | カスタム JSON スクレイパー端点。`%s` は URL エスケープ済みタイトルに置換 |
| `AI_TAG_BIN` | 空 | 外部 AI タグ付けツール（メディアパスを引数に、1 行 1 タグ） |

## 7. FAQ

**スキャンが長い間「スキャン中」のままです。**
大規模フォルダの初回スキャンは時間がかかります（ファイルごとに ffprobe + ポスター生成）。
進捗はリアルタイム表示され、いつでも停止できます。再スキャンは変更ファイルのみ処理されるため
はるかに速いです。macOS の `._` ファイルと `.m3u8` セグメントフォルダは自動スキップされます。

**MKV/HEVC がブラウザで再生できません。**
ブラウザは H.264/VP9 のみデコードできます。VideoCMS は MKV/HEVC を HLS にリアルタイム
トランスコードするか、ダウンロードしてローカルで再生できます。

**ドラマはどうやって検出されますか？**
`S01E01`、`E01`、`EP1`、`第1集`、末尾数字を含むファイル名を共通プレフィックスでグループ化し、
グループごとに 2 話以上で登録します。命名規則が認識されない場合はファイル名を調整するか、
開発者にパターンの追加を依頼してください。

**TMDB スクレイピングが失敗します。**
`TMDB_API_KEY` の設定と、サーバーから api.themoviedb.org へのアクセスを確認してください。
制限されたネットワークではスクレイピングのみ使えませんが、他の機能は影響を受けません。

**スマホからはどうアクセスしますか？**
同じネットワークに接続し、`make serve` を実行。`ipconfig getifaddr en0` でサーバーの IP を
確認し、`http://<IP>:8080` を開きます。初回は macOS のファイアウォール許可が必要な場合があります。

**公開アクセスしても安全ですか？**
デフォルトは平文 HTTP + 開発用 JWT です。信頼できる LAN 以外に公開する場合は、
HTTPS リバースプロキシを設定し、`JWT_SECRET` を必ず変更してください。

**ファイルを削除せずにコンテンツを隠すには？**
管理者はタイトル単位（管理 → ブロック中のコンテンツ）またはライブラリ単位
（管理 → ライブラリ → ライブラリをブロック）でブロックできます。ブロックされた
コンテンツは全ユーザーの全一覧から消え、解除で即座に復元されます。一般ユーザーも
パスフィルターで任意のサーバーパスを自分だけ非表示にできます。
